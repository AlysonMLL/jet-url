Dúvidas Frequentes

Entenda como o Jet.URL processa seus links e dados.

Como o rastreamento de dispositivos funciona?

Nosso backend analisa o cabeçalho (User-Agent) da requisição no momento do clique, extraindo apenas a categoria do dispositivo (Mobile, Desktop ou Tablet), garantindo performance e privacidade, sem coletar dados sensíveis.

Os links e métricas expiram?

Não. Uma vez gerado, o link curto e seu respectivo QR Code permanecem ativos permanentemente, armazenados e roteados através de nosso banco de dados relacional.

Posso exportar os dados de clique?

Sim. O Jet.URL possui uma integração voltada para pipelines de ETL. Se você é um desenvolvedor, pode acessar a rota de exportação para baixar todo o banco em formato CSV.

O serviço é gratuito?

Sim, o Jet.URL oferece um serviço gratuito com nossas funcionalidades.
